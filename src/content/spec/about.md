# 关于

这里是一个人的技术笔记本。

主要用于记录做东西过程中遇到的问题和解法——**同一个坑不想踩第二次**。

## 这个站怎么搭的

纯静态站点，没有后端，没有数据库，没有追踪脚本。

- 框架：[Astro](https://astro.build/)
- 主题：[Fuwari](https://github.com/saicaca/fuwari)
- 部署：GitHub Actions → GitHub Pages

文章全部是 Markdown，写在仓库里，随时可以整体搬走。
