# 为什么栽一棵树最好的时间是现在

2022 年 1 月，我建了一个叫 `alex.github.io` 的仓库，描述栏写了四个字：个人博客。

然后就再也没有然后了。将近五年过去，那个仓库里一个文件都没有，提交数是 0。GitHub Pages 也没开过，任何人点进去都是一个 404。

## 这次换了套思路

以前每次想搭博客，卡住的都是同一件事：**搭起来太费劲，写完还要记得怎么发**。本地装环境、配主题、输命令构建、推送、等部署——中间任何一步断了，热情就没了。

所以这次的标准只有一个：**让"写"成为唯一需要动作的事**。

具体是这样搭的：

- **Astro** 做静态站点，输出纯 HTML，没有任何后端依赖
- **Fuwari** 主题，卡片式布局，自带深色模式、文章目录、全文搜索
- **GitHub Actions** 自动构建部署，推上去就是一分钟上线

发一篇新文章的完整流程是：在 `src/content/posts/` 下新建一个 `.md`，写上 frontmatter 和正文，commit。不用本地开任何东西——直接在 GitHub 网页上操作也行，手机也行。

## 以后大概会写什么

主要是自己动手做东西过程中踩过的坑。前端工具链、桌面端打包、还有一些零碎的脚本和自动化。

写下来主要是给自己看的：**同一个坑不想踩第二次**。如果有人正好也遇到，那更好。

```bash
# 本地预览的时候
pnpm install
pnpm dev
```

就这些。开始吧。
